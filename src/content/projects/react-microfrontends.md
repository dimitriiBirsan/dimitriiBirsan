## Context

I work on a React application made up of microfrontends. My part is to build and maintain frontend functionality, write Cypress tests, and contribute to the delivery pipelines.

## Challenge

A component can work on its own and still leave a broken user journey. In a microfrontend application, the interesting part is how that functionality fits into the rest of the experience. That’s why my work also includes tests that follow the user through the application.

## My contribution

- Develop and maintain frontend functionality within the React microfrontend project.
- Create Cypress end-to-end tests and expand E2E coverage.
- Contribute to DevOps processes.
- Create and maintain CI/CD pipelines, working on frontend delivery and testing workflows.

## Architecture & technologies

React provides the UI within the existing microfrontend architecture. I use Cypress to exercise user workflows and work on CI/CD alongside the frontend changes.

## Outcome & current status

This is an ongoing engagement. I’m delivering frontend functionality and adding automated E2E coverage as the work progresses, alongside maintaining and improving the delivery workflow.
